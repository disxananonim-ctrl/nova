Mode offline

Koneksi model AI

Mode offline tetap tersedia tanpa internet. Untuk jawaban lebih luas seperti asisten AI modern, hubungkan API model yang kompatibel dengan format OpenAI (Groq, OpenAI, DeepSeek, OpenRouter, Together, atau server sendiri). Perlu internet dan API key.

Privasi: pesan chat dikirim ke penyedia API saat mode online aktif. API key hanya disimpan di browser ini jika kamu mencentang "Ingat API key"; jangan centang di komputer bersama dan jangan membagikan file/ekspor browser yang berisi kunci. Bila file ini dibuka langsung dari penyimpanan (alamat file://), sebagian browser berbagi localStorage antar file HTML lokal, jadi lebih aman membiarkan opsi ini tidak dicentang. Jangan menempel key ke dalam kode HTML. Penggunaan API dapat dikenai biaya.

Mode offline berjalan lokal dan terbatas. AI online opsional mengirim pesan ke penyedia API; foto tidak dikirim sebagai data gambar. Mikrofon dapat memakai layanan online.
